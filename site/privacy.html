Privacy Policy

Effective August 5, 2026

This Privacy Policy governs the collection, use, and disclosure of data by the Faber Discord application ("Bot"), in compliance with the Discord Developer Terms of Service and Developer Policy.

1. Information We Collect

In operating the Bot and interacting with Discord APIs, we collect only data necessary for core functionality:

  • Discord IDs: User IDs and Server (Guild) IDs required to process slash commands and maintain server-specific configurations.
  • Interaction Data: Command inputs, parameters, and timestamps submitted during direct interaction with the Bot.
  • No Sensitive Data: We do not collect, store, or process real names, physical addresses, financial details, or direct private messages outside explicit command invocation.

2. Data Usage & Storage

  • Data is processed strictly to provide, maintain, and improve the Bot's slash-command features.
  • We do not sell, rent, trade, or monetize user data or server metadata.
  • Data is retained only as long as necessary to fulfill operational requirements or comply with Discord developer policies.

3. Data Security

  • We implement technical and administrative security measures (including encrypted transport via HTTPS/TLS and restricted database access) to protect stored information against unauthorized access, alteration, disclosure, or destruction.

4. User Rights & Contact

  • Server administrators or users may request data deletion or inquire about privacy practices by opening an issue on the source repository.
